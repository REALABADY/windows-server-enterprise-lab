# Group Policy Management

## Objective

Apply centralized configuration and restrictions to domain users.

## Implementation

- Created and configured Group Policy Objects.
- Applied an HR user policy.
- Restricted access to Control Panel and PC settings for HR users.
- Tested policy application from the domain client.

## Validation

The HR policy was tested from PC-IT01 and the configured restriction was successfully applied.

## What This Demonstrates

This lab demonstrates the basic enterprise workflow of:

Active Directory -> Organizational structure -> Group Policy -> Client-side policy enforcement
