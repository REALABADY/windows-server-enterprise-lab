# Active Directory Domain Services

## Objective
Build a basic Active Directory environment for centralized identity and device management.

## Implementation
- Installed the AD DS role on DC01.
- Created the `abadi.local` domain.
- Promoted the server to a Domain Controller.
- Created Organizational Units to organize departmental objects.
- Created domain users and security groups.

## Validation
- Windows 11 client PC-IT01 successfully joined the domain.
- Domain user authentication was tested from the client.
