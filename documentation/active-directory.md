# Active Directory Domain Services

## Objective

Build a basic Active Directory environment for centralized identity, authentication, and device management.

## Environment

- Domain Controller: DC01
- Domain: abadi.local
- Client: Windows 11 Pro (PC-IT01)

## Implementation

1. Installed the Active Directory Domain Services (AD DS) role.
2. Created the abadi.local domain.
3. Promoted DC01 to a Domain Controller.
4. Created Organizational Units for departmental organization.
5. Created domain users.
6. Created security groups.
7. Joined PC-IT01 to the domain.

## Validation

- Confirmed domain connectivity.
- Confirmed successful domain join.
- Tested domain-user authentication from the client.
